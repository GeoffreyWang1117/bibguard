# Integrations

Skill / prompt templates for AI coding agents that wrap `bibguard`.

## Claude Code

Copy the skill prompt into your Claude Code commands directory:

```bash
cp integrations/claude-code/ref-check.md ~/.claude/commands/ref-check.md
```

Then invoke with `/ref-check references.bib` in any Claude Code session.

## Codex (OpenAI)

Place `integrations/codex/ref-check.md` in your Codex agents directory
or paste its contents as a system prompt.
